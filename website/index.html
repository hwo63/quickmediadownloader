Sẵn sàng trong 30 giây

Cài đặt theo cách của bạn.

Tải trực tiếp bản đóng gói sẵn hoặc tự build từ mã nguồn mở cho Chrome, Edge và Brave.

Cài đặt ngay từ bản Release đóng gói sẵn (không cần build)

  1. Truy cập trang GitHub Releases và tải tệp QuickMediaDownloader-*.zip mới nhất.
  2. Giải nén tệp .zip vào một thư mục cố định trên máy tính của bạn.
  3. Mở trang tiện ích của trình duyệt (chrome://extensions, edge://extensions hoặc brave://extensions).
  4. Bật công tắc Developer mode ➔ bấm Load unpacked ➔ chọn thư mục vừa giải nén.

Nạp vào Google Chrome

  1. Mở thanh địa chỉ Chrome và nhập chrome://extensions rồi nhấn Enter.
  2. Bật Developer mode (Chế độ dành cho nhà phát triển) ở góc trên bên phải.
  3. Bấm Load unpacked (Tải tiện ích đã giải nén) và chọn thư mục dist/QuickMediaDownloader (hoặc thư mục giải nén từ bản Release).
  4. Ghim biểu tượng QuickMedia Downloader lên thanh công cụ để bật/tắt nhanh và xem thống kê.

Nạp vào Microsoft Edge

  1. Mở thanh địa chỉ Edge và nhập edge://extensions rồi nhấn Enter.
  2. Bật công tắc Developer mode ở cột bên trái màn hình.
  3. Bấm Load unpacked và chọn thư mục dist/QuickMediaDownloader (hoặc thư mục giải nén từ bản Release).

Nạp vào Brave Browser

  1. Mở thanh địa chỉ Brave và nhập brave://extensions rồi nhấn Enter.
  2. Bật công tắc Developer mode ở góc trên bên phải.
  3. Bấm Load unpacked và trỏ vào thư mục dist/QuickMediaDownloader (hoặc thư mục giải nén từ bản Release).

Build và đóng gói từ mã nguồn mở

Yêu cầu zsh, python3 và zip trên macOS hoặc Linux:

git clone https://github.com/hwo63/quickmediadownloader.git
cd quickmediadownloader
chmod +x scripts/build-release.sh
./scripts/build-release.sh

Sau khi chạy xong, thư mục nạp trực tiếp nằm tại dist/QuickMediaDownloader/ và gói nén sẵn sàng chia sẻ nằm trong releases/.
